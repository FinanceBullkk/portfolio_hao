The Evolution

Replacing fragmented scripts with a zero-friction platform

In early iterations, issuing 300+ certificates required juggling multiple disjointed tools: Canva for bulk creation, online splitters for single-page PDFs, desktop Python scripts for renaming, Google Drive for hosting, and Google Sheets Apps Script for email dispatching. It took 3 to 5 days per batch and required technical oversight.

I architected CertStudio to consolidate the entire lifecycle into a single, high-performance web platform that non-technical event coordinators can run end-to-end without developer assistance.

Automated · 1-Click Upload & Lossless Vector Splitting
Drag & Drop Merged Canva PDF Instant

Users upload a single merged PDF exported from Canva (20–100+ pages). The backend engine uses pypdf and pypdfium2 to extract individual vector pages losslessly without raster compression, while generating ultra-lightweight cached thumbnails for instantaneous UI rendering.

2
Automated · OCR Extraction & Sheet-Driven Matching
Vietnamese OCR & Diacritic Normalization

The core safety guarantee: Every page reads its own text layer. pdfplumber extracts student names and certificate serials printed directly on the certificate. The engine applies Unicode diacritic normalization to match against uploaded Excel rosters, eliminating order-dependent misalignment risks.

Page #01: "Nguyễn Văn A" OCR text ✓Roster match ✓ Matched → Ready
Diacritics normalized across UTF-8 forms. Name mismatches are flagged for review, never guessed.

3
UI / UX · Desktop-Grade Studio Workspace
Zero-Scroll Review & Click-to-Zoom Lightbox

Designed for high-speed verification: The application viewport is strictly locked at 100vh with zero page scrolling. Organizers navigate records using keyboard arrows and press Enter to save and auto-advance. Clicking any certificate opens a full-screen interactive lightbox for high-DPI inspection.

4
Automated · Pre-Flight Audit & High-Volume Delivery
Pre-Flight Safety Check & SMTP Dispatch

Before sending, a **Pre-Flight Safety Audit** validates recipient email syntax and flags missing addresses. Organizers can run a **Simulation (Dry-Run)** or dispatch via live Gmail/Outlook SMTP with automated throttling and real-time execution logs. Finished batches can be exported as a bundled **ZIP archive** or **Excel CSV delivery report** in 1 click.
