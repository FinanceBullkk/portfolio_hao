01 · The Problem

A week of fragmented manual work & silent failure risks

Issuing ~300 training certificates per cycle previously required juggling 6 disjointed tools: designing in Canva, splitting multi-page PDFs one-by-one through free web tools (hitting file size and timeout caps), running local Python desktop scripts for renaming, uploading hundreds of files to Google Drive, and triggering Google Sheets Apps Script to send individual emails via Gmail.

This fragmented process created three critical bottlenecks:

01
Severe Operational Drag (3 to 5 Days per Batch)
Event organizers and L&D coordinators spent entire days manually splitting files, verifying names, copying Drive links, and handling email attachments.
02
Catastrophic Order-Shift Bug (Silent Mismatch Risk)
Relying on file order or mapping files meant a single skipped page or re-sorted spreadsheet row shifted every subsequent file by one position — silently emailing 40+ students someone else's certificate.
03
Developer Dependency & Lack of Visibility
When online splitters crashed or SMTP limits triggered, non-technical coordinators had no real-time logs to diagnose errors and required engineering intervention.
02 · Objectives & Constraints

Engineering goals for a zero-friction certificate studio

To eliminate the multi-tool fragmentation and guarantee 100% delivery accuracy, the system was designed around four non-negotiable requirements:

Pillar 1 · Ingestion & Vector Splitting
Lossless Vector PDF Splitting & 1.8KB Thumbnail Caching

The backend extracts individual single-page vector PDFs using pypdf without raster quality loss. Simultaneously, pypdfium2 generates ultra-lightweight 1.8KB JPEG rendering thumbnails with CSS content-visibility: auto to ensure silky-smooth 60 FPS scrolling across large batches.

2
Pillar 2 · OCR Extraction & Sheet Alignment
Vietnamese OCR & Unicode Diacritic Normalization

To eliminate the catastrophic order-shift bug, every page names itself. pdfplumber extracts student names and certificate IDs printed directly on the certificate. The engine applies Unicode NFC/NFD diacritic normalization to match against uploaded rosters with 100% precision.

Every page names itself from its own text. Diacritics and casing are normalized before comparing.

3
Pillar 3 · UI / UX Architecture
Zero-Scroll 60 FPS Studio Workspace & Lightbox

The application viewport is strictly locked at 100vh with zero page scrolling. The left table scrolls independently while the certificate preview inspector and action bar stay permanently anchored. Clicking the preview image opens an interactive full-screen Lightbox for high-DPI inspection.

4
Pillar 4 · Delivery & Safety Governance
Pre-Flight Safety Audit & Throttled SMTP Dispatch

Before dispatching live emails, an automated Pre-Flight Safety Audit validates recipient email syntax and flags missing addresses. Organizers can run a Simulation (Dry-Run) or dispatch via live Gmail/Outlook SMTP with automated throttling (avoiding spam blocks) and live streaming execution logs.
