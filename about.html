How I work

Map the process, then remove the manual part

I start from how a team actually works today: the spreadsheet, the inbox, the copy-paste. Not from a tool I want to try. From there I scope the smallest thing that removes the painful step, build it so a non-technical person can run and trust it, and write the handover doc. Reliability is usually the real feature. Dry runs, idempotency, failures you can see, and no silent guessing.
