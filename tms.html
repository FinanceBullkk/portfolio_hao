Differentiator Anatomy

The directory sync is the part that can do real damage

A directory sync can touch each record in one pass. Done carelessly it can lock people out of their own accounts, and IT absorbs the fallout. This is how the write path is designed to avoid that.

Under the hood

What makes it more than a booking tool

01
It keeps a learning record, not just bookings
Most booking tools forget the session once it happens. Here every employee's history, hours and credentials land in one profile.
02
Completion is measured, not judged
Three gates replace the instructor's opinion. Each certificate carries a verification code and an expiry date.
03
The sync is designed to preserve active access
Matching on empCode lets an update skip password hashing entirely for existing staff.
04
The export is treated as untrusted output
The HR Excel export escapes any cell starting with =, +, - or @, designed to prevent formula injection.
